# Демо-банк в корне репозитория, со своими служебными адресами

Гайд (`architecture.md`, раздел «Тесты») кладёт подделку внешнего сервиса в `tests/fake_<service>/` и даёт ей
служебные адреса `/_test/inject`, `/_test/outbox`, `/_test/reset`. Демо-банк нужен не только тестам: ТЗ требует
«README с инструкцией по запуску на тестовых данных или демо-страницах», и по демо-банку проверяющий запускает
прототип вручную, в Docker и для `evaluate` (эталонная выписка лежит рядом с ним). Поэтому демо-банк — отдельный
пакет `demo_bank/` в корне, а не часть тестов. Служебные адреса у него свои — `/_test/mode` (режим демо-банка)
и `/_test/api-calls` (журнал запросов истории): кабинет банка ничего не отправляет наружу, и подсовывать ему
входящие события незачем.
