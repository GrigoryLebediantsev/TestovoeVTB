# Кроме сквозных тестов — тесты чистых функций разбора и проверок

Гайд (`architecture.md`, раздел «Тесты») допускает только сквозные тесты «чёрным ящиком». В прототипе много
вариантов форматов кабинета банка (даты, суммы, валюты, статусы) и чистых проверок выписки (период, связи,
дубликаты, маскирование); перебирать их через запуск браузера медленно и неудобно. Поэтому, как решено
в спецификации, есть второй шов: тесты чистых функций разбора форматов в адаптере банка и проверок в `domain`.
Главный шов по-прежнему — запуск всего приложения; внутренние слои в тестах не подменяются.
