# Без базы данных: выписка сохраняется в файлы

Архитектурный гайд (`architecture.md`) строит сервис вокруг Postgres и ORM, но этот прототип — разовый запуск
из командной строки, результат которого — файлы выписки. Поэтому базы данных нет: доменные модели — обычные классы
данных без ORM, вместо адаптера БД — адаптер записи файлов, миграций нет. Остальные правила гайда (слои, протоколы,
стиль) соблюдаются.
