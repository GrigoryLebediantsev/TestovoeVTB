# Порядок способов извлечения: экспорт → ответы сервера → разбор страницы

Разметка кабинета банка нестабильна, а экспорт и данные, которые страница сама получает от сервера банка, меняются
реже. Поэтому адаптер банка для каждого продукта пробует способы по порядку: экспорт файла из кабинета, чтение
ответов сервера на запросы самой страницы (без собственных запросов), разбор страницы как запасной вариант.
Использованный способ записывается в отчёт о полноте извлечения.
