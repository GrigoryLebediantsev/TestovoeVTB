# Демо без окна — скрипт поверх тестовых помощников, Docker — один образ без compose

Гайд (`architecture.md`, разделы «Структура каталогов» и «Тесты») не предусматривает папку `scripts/`
и описывает тестовое окружение через `docker-compose.test.yml` и `make test`. Здесь проверяющему нужно запустить
тесты и демо в контейнере, где нет окна и некому войти в кабинет. Поэтому демо — скрипт `scripts/headless_demo.py`,
который играет клиента так же, как сквозные тесты, и для этого переиспользует `tests/e2e_support.py`: запуск
демо-банка, Chromium без окна и действия клиента в браузере. Отдельной копии этих помощников нет, чтобы демо
и тесты не расходились. Демо-банк и Chromium запускаются внутри одного процесса, внешних сервисов нет, поэтому
достаточно одного образа (`Dockerfile`) без compose: `docker run ... pytest` вместо `make test`.
