# Оценка качества — отдельный контейнер сценариев, без настроек извлечения

По гайду все сценарии собраны в одном `Usecase`, а `Settings` загружаются при импорте `config.py`. Команде
`evaluate` нужны только файлы выписки и эталона, а банк, браузер и обязательные настройки извлечения из `.env`
(банк, период, адрес кабинета) ей не нужны. Чтобы оценку можно было запускать без `.env`, сценарии оценки живут
в отдельном контейнере `EvaluationUsecase` с одной зависимостью — чтением файлов, а `main.py` загружает
настройки и создаёт браузер только для извлечения.
