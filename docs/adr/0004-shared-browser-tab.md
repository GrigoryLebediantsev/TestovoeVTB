# Адаптер банка работает в общей вкладке окна клиента

По гайду адаптер наследует базовый класс своей инфраструктуры и сам владеет подключением. Здесь страница согласия,
вход клиента в кабинет и чтение данных должны идти в одной и той же вкладке: клиент нажимает «Разрешаю» и тут же
видит страницу входа банка. Поэтому браузером владеет только адаптер окна клиента (`BrowserWindow`, наследник
`BrowserBase`), а адаптер банка получает его в конструкторе и работает с его вкладкой. Подключение и закрытие
браузера по-прежнему выполняются только в `main.py`.
