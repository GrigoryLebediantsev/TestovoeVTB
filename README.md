# Извлечение комплексной банковской выписки

Прототип на Python. Клиент сам входит в личный кабинет банка в браузере, а прототип после этого извлекает данные
о его продуктах (счета, карты, накопительные счета, кредиты) и операциях за период. Результат — нормализованная
**комплексная выписка** (JSON и/или CSV) и **отчёт о полноте извлечения**.

- Перед чтением данных клиент в браузере даёт согласие: видно банк, период и что будет прочитано.
- Логин, пароль и код из СМС клиент вводит сам. Прототип их не видит и не сохраняет.
- Данные извлекаются тремя способами по порядку: экспорт файла → ответы сервера банка на запросы самой страницы →
  разбор страницы.
- Работает на локальном **демо-банке**: учебном кабинете с режимами сбоев и эталонной выпиской для оценки качества.

## Быстрый старт в Docker

Нужен только Docker. Образ построен на официальном образе Playwright для Python, браузер уже внутри.

```bash
docker build -t bank-statement .

# Демо без окна: весь сценарий на демо-банке, действия клиента выполняет скрипт
docker run --rm --ipc=host bank-statement

# Все тесты
docker run --rm --ipc=host bank-statement pytest
```

`--ipc=host` — рекомендация Playwright для Chromium в контейнере: без неё браузеру может не хватить общей памяти.

Демо (`scripts/headless_demo.py`) поднимает демо-банк и Chromium без окна, запускает прототип в режиме `cdp`,
нажимает «Разрешаю», входит в кабинет (`demo` / `demo`, код `0000`), затем печатает лог прототипа, текст итоговой
страницы из браузера и оценку качества по эталонной выписке. Код завершения — код прототипа (см. «Коды завершения»).

Другой режим демо-банка и сохранение результата на свою машину:

```bash
docker run --rm --ipc=host -v "$PWD/output:/app/output" bank-statement \
    python -m scripts.headless_demo --mode load_error
```

На Linux папка `output` должна быть доступна на запись пользователю контейнера `pwuser` (uid 1001).

## Локальный запуск

Нужны Python 3.14 и [uv](https://docs.astral.sh/uv/).

```bash
uv sync                                  # зависимости из uv.lock
uv run playwright install chromium       # браузер для Playwright
cp .env.example .env                     # настройки по умолчанию подходят для демо-банка
```

### Ручной сценарий на демо-банке

1. В первом терминале запустите демо-банк:

   ```bash
   uv run python -m demo_bank --port 8000
   ```

   Режим сбоя задаётся аргументом: `uv run python -m demo_bank --port 8000 --mode slow`.

2. Во втором терминале запустите прототип:

   ```bash
   uv run python -m src.main
   ```

3. Откроется окно браузера со страницей согласия: банк, период и список данных. Нажмите **«Разрешаю»**.
   «Отказываюсь» завершает программу, ничего не прочитав.
4. В той же вкладке откроется страница входа демо-банка. Введите логин `demo`, пароль `demo`, затем код
   из СМС `0000`.
5. Прототип сам заметит вход, обойдёт продукты и покажет в браузере итоговую страницу: число продуктов,
   операций, предупреждения. Сумм и номеров на ней нет.
6. Закройте окно. Временный профиль браузера удаляется вместе с cookies. В терминале будет путь к папке
   с результатом, например `output/demo_bank_20261008-124858/`.
7. Оцените качество выписки по эталонной:

   ```bash
   uv run python -m src.main evaluate output/demo_bank_20261008-124858
   ```

### Режимы демо-банка

| Режим            | Что происходит в кабинете                                                                      |
|------------------|-----------------------------------------------------------------------------------------------|
| `normal`         | Обычная работа                                                                                 |
| `load_error`     | Страница кредита и история дебетовой карты всегда отвечают ошибкой сервера                      |
| `changed_format` | Даты словами (`10 июня 2026`), суммы с кодом валюты (`-1450.00 RUB`), один статус переименован |
| `changed_layout` | Другие классы таблицы операций и кнопки «Показать ещё»                                         |
| `slow`           | Каждый ответ с задержкой, первый запрос истории карты — 5 секунд; повтор после таймаута виден при `DEMO_BANK__ACTION_TIMEOUT_SECONDS=2` |
| `empty`          | У продуктов нет операций                                                                       |
| `no_period_filter` | В истории продуктов нет фильтра периода: кабинет отдаёт всю историю                          |

### Свой открытый Chrome (режим `cdp`)

Прототип может подключиться к уже открытому Chrome клиента, чтобы не входить в кабинет заново. Chrome должен быть
запущен с портом отладки. Начиная с Chrome 136 порт работает только с отдельной папкой профиля:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
    --remote-debugging-port=9222 --user-data-dir="$HOME/chrome-statement-profile"
```

В `.env`: `BROWSER__MODE=cdp`, `BROWSER__CDP_URL=http://127.0.0.1:9222`. Прототип откроет новую вкладку,
а браузер и другие вкладки клиента не закроет.

## Настройки `.env`

Все настройки читаются из `.env` или переменных окружения. Имя — `РАЗДЕЛ__ПОЛЕ`. Если обязательной настройки нет,
прототип сразу печатает список недостающих переменных и завершается с кодом 1. Образец — `.env.example`.

| Переменная                              | По умолчанию            | Назначение                                                                       |
|-----------------------------------------|-------------------------|----------------------------------------------------------------------------------|
| `EXTRACTION__BANK`                      | обязательна             | Банк: пока только `demo_bank`                                                    |
| `EXTRACTION__PERIOD_FROM`               | обязательна             | Начало периода, `ГГГГ-ММ-ДД`                                                     |
| `EXTRACTION__PERIOD_TO`                 | обязательна             | Конец периода, `ГГГГ-ММ-ДД`                                                      |
| `EXTRACTION__FORMAT`                    | `both`                  | Файлы выписки: `json`, `csv` или `both`; отчёт пишется всегда                    |
| `DEMO_BANK__BASE_URL`                   | обязательна             | Адрес кабинета демо-банка                                                        |
| `DEMO_BANK__LOGIN_TIMEOUT_SECONDS`      | `300`                   | Сколько ждать, пока клиент войдёт                                                |
| `DEMO_BANK__ACTION_TIMEOUT_SECONDS`     | `15`                    | Таймаут одного действия в кабинете: открыть страницу, дождаться элемента         |
| `DEMO_BANK__RETRY_COUNT`                | `2`                     | Сколько раз повторить чтение после таймаута или ошибки кабинета                   |
| `BROWSER__MODE`                         | `launch`                | `launch` — собственный браузер с окном, `cdp` — уже открытый Chrome клиента      |
| `BROWSER__PROFILE_DIR`                  | не задан                | Постоянный профиль для `launch`; без него профиль временный и удаляется          |
| `BROWSER__CDP_URL`                      | `http://127.0.0.1:9222` | Адрес отладки Chrome для `cdp`                                                   |
| `BROWSER__CONSENT_TIMEOUT_SECONDS`      | `300`                   | Сколько ждать решения клиента на странице согласия                               |
| `BROWSER__WINDOW_CLOSE_TIMEOUT_SECONDS` | `600`                   | `launch`: сколько ждать, пока клиент закроет окно с итогом                        |
| `STORAGE__OUTPUT_DIR`                   | `output`                | Папка результатов                                                                |
| `LOGGER__LEVEL`                         | `INFO`                  | Уровень лога                                                                     |
| `LOGGER__PRETTY_CONSOLE`                | `false`                 | `true` — цветной вывод в консоль, `false` — JSON                                 |
| `LOGGER__APP_NAME`                      | `app`                   | Имя приложения в записях лога                                                    |

## Команды

| Команда                                                           | Что делает                                                     |
|-------------------------------------------------------------------|----------------------------------------------------------------|
| `uv run python -m src.main`                                       | Извлечь выписку за период из `.env`                            |
| `uv run python -m src.main --from 2026-06-01 --to 2026-06-30`     | Извлечь выписку за другой период                               |
| `uv run python -m src.main evaluate <папка или statement.json>`   | Сравнить выписку с эталонной демо-банка; `.env` не нужен       |
| `uv run python -m src.main evaluate <путь> --reference <файл>`    | Сравнить с другой эталонной выпиской                           |
| `uv run python -m demo_bank --port 8000 [--mode <режим>]`         | Запустить демо-банк                                            |
| `uv run python -m scripts.headless_demo [--mode <режим>]`         | Демо без окна, как в Docker                                    |
| `uv run pytest`                                                   | Все тесты: сквозные на демо-банке и тесты чистых функций       |
| `uv run ruff check . && uv run ruff format --check .`             | Проверка стиля                                                 |
| `uv run mypy .`                                                   | Проверка типов (`--strict`)                                    |

Оценка `evaluate` печатает точность (доля операций выписки, найденных в эталоне), полноту (доля операций эталона,
найденных в выписке), долю нормализованных полей, совпавших с эталоном, и число предупреждений.

### Коды завершения

| Код | Значение                                                                                    |
|-----|---------------------------------------------------------------------------------------------|
| `0` | Выписка сохранена, всё извлечено полностью                                                  |
| `2` | Выписка сохранена, но есть предупреждения, ошибки или продукты с пропусками                  |
| `1` | Выписку сформировать не удалось: отказ от согласия, таймаут входа, неверные настройки и т.п. |

На демо-банке в режиме `normal` код всегда `2`: в данных специально есть дубликаты операций карты.

## Результат запуска

Каждый запуск пишет файлы в свою папку `output/<банк>_<ГГГГММДД-ЧЧММСС>/`:

| Файл                     | Содержимое                                                       |
|--------------------------|------------------------------------------------------------------|
| `statement.json`         | Выписка целиком: банк, время извлечения, период, продукты, операции |
| `products.csv`           | Продукты таблицей, вложенные поля — плоскими колонками           |
| `transactions.csv`       | Операции таблицей                                                |
| `extraction_report.json` | Отчёт о полноте: согласие, статус каждого продукта, предупреждения и ошибки |

Схема полей и пример — в [docs/output-schema.md](docs/output-schema.md).

## Структура репозитория

```
src/                 прототип: domain, dto, usecase, adapter, controller (слои — в docs/architecture.md)
shared/              инфраструктура без предметной области: браузер, логирование, загрузка настроек, запись JSON/CSV
demo_bank/           демо-банк (FastAPI) и эталонная выписка reference_statement.json
scripts/             демо без окна
tests/               сквозные тесты на демо-банке и тесты чистых функций
docs/                документация и ADR
Dockerfile           образ для тестов и демо
```
